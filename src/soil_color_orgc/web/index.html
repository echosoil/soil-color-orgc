    Method and provenance
    
        
    
      
    
      
    Scientific scope
    This is an exploratory colour characterization tool, not a laboratory measurement or validated organic carbon prediction. Colour depends on lighting, moisture, camera and sample preparation.
    
    
    
  
    
  
    Handling your image
    Preview, optional grey detection and analysis send the original image to the server in separate requests. The application processes it in memory and does not persist uploaded photographs. This is a restricted research preview, not a public production service.
