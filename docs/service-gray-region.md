# Grey reference inspection and override

Use Detect automatically after uploading a photo. The blue rectangle is the final trimmed detector region, and the small rectangles are the actual central measurement areas of the 11 patches. The detector scores candidate lower-image bands and trims the selected region. A fixed fallback is now explicitly identified; strict service analysis refuses to apply correction to an unaccepted fallback. The historical CLI still uses its previous fallback behavior. The ramp check reuses the previous correlation/contrast/negative-step heuristics on the final crop, not independent validation. A visually plausible grey strip and improved imbalance do not prove calibrated physical colour.

Tick manual grey to draw an exact horizontal rectangle instead of the soil ROI. Numeric coordinates are also editable. Include all patches, black left, white right, no margins. Check manual strip calls the same locator used by analysis. Untick manual grey to return to soil ROI editing. Enable grey correction separately. After analysis the region, sampled patch centres and per-patch measured/target/corrected RGB appear in results/exports. If the ramp fails, uncorrected analysis is returned with warnings. No automatic acceptance of a poor strip.

POST /api/v1/analyze?gray=true&gray_roi=x0,y0,x1,y1 uses the exact manual rectangle; omitting gray_roi uses automatic detection. Coordinates refer to the oriented, downscaled 800-pixel preview.
